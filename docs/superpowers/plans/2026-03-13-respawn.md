# Respawn Mechanism for Ralph

## Context

Ralph exits on recoverable failures (exit 1: max iterations, exit 2: stuck) and never retries. In production, this means a human must manually re-run. The verify feedback loop (just added) helps within a single run, but across runs Ralph starts cold. An optional `--respawn N` flag would auto-restart the iteration loop on recoverable exits while preserving PRD state.

Off by default so development experience is preserved (you see every exit to identify issues).

## Approach

**Extract the iteration loop into `run_iteration_loop()`, wrap with outer respawn loop.**

- Every `exit N` inside the loop becomes `return N`
- Outer loop checks return code: 0/3 → exit immediately, 1/2 → respawn if allowed
- Setup code (config validation, lockfile, branch) stays outside — does NOT re-run
- Stuck detection (`STUCK_STORY`/`STUCK_COUNT`) resets on each respawn (fresh chances)
- Verify feedback file cleaned up at start of each respawn

### 3. Add outer respawn loop (replaces current inline loop location)

```bash
mkdir -p "$LOG_DIR"
RESPAWN_COUNT=0

while true; do
  if [ "$RESPAWN_COUNT" -gt 0 ]; then
    echo ""
    echo "============================================="
    echo "  RESPAWN $RESPAWN_COUNT of $RESPAWN_MAX"
    echo "============================================="
    echo "[$(date)] Respawn $RESPAWN_COUNT/$RESPAWN_MAX" >> "$PROGRESS_FILE"
    sleep 5
  fi

  set +e
  run_iteration_loop
  LOOP_EXIT=$?
  set -e

  # Success or contract violation: always terminal
  if [ "$LOOP_EXIT" -eq 0 ] || [ "$LOOP_EXIT" -eq 3 ]; then
    exit "$LOOP_EXIT"
  fi

  # Recoverable (1 or 2): respawn if allowed
  if [ "$RESPAWN_MAX" -eq 0 ] || [ "$RESPAWN_COUNT" -ge "$RESPAWN_MAX" ]; then
    exit "$LOOP_EXIT"
  fi

  RESPAWN_COUNT=$((RESPAWN_COUNT + 1))
done
```

Note: `set +e` / `set -e` around the function call is needed because ralph uses `set -e` and a non-zero return would otherwise exit the script.

### 4. Tests (`tests/respawn.bats`)

```bash
@test "--respawn is off by default" {
  use_fixture "valid-prd.json"
  run "$RALPH_DIR/ralph.sh" 1
  [ "$status" -eq 1 ]
  [[ "$output" != *"RESPAWN"* ]]
}

@test "--respawn retries on recoverable exit" {
  use_fixture "valid-prd.json"
  run "$RALPH_DIR/ralph.sh" --respawn 1 1
  [ "$status" -eq 1 ]
  [[ "$output" == *"RESPAWN 1 of 1"* ]]
}

@test "--respawn does not retry contract violation" {
  use_fixture "valid-prd-3-incomplete.json"
  export MOCK_CLAUDE_BEHAVIOR="mutate"
  run "$RALPH_DIR/ralph.sh" --respawn 5 1
  [ "$status" -eq 3 ]
  [[ "$output" != *"RESPAWN"* ]]
}

@test "--respawn exits 0 when stories complete" {
  use_fixture "valid-prd.json"
  export MOCK_CLAUDE_BEHAVIOR="pass"
  run "$RALPH_DIR/ralph.sh" --respawn 2 5
  [ "$status" -eq 0 ]
  [[ "$output" == *"Ralph completed all tasks!"* ]]
}
```
